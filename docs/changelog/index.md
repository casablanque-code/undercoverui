# Регуляторный Changelog

Законы меняются. Когда регулятор выпускает новое разъяснение — компоненты с соответствующим тегом обновляются, а здесь появляется запись с объяснением что изменилось и почему.

Это не журнал релизов кода (для этого Git history) — это журнал **причин**, по которым код изменился.

## Как подписаться

RSS-фид: `/docs/changelog/feed.xml` (появится после Phase 2 — см. [роадмап](https://github.com/casablanque-code/undercoverui)).

Email-уведомления — в разработке.

## Формат записи

Каждая запись связывает регуляторное событие с конкретными изменениями в реестре:

```md
## [Дата] Заголовок изменения

**Источник:** ссылка на официальное разъяснение регулятора
**Затронутые компоненты:** список с указанием версий до/после
**Что изменилось:** конкретика, не общие слова
```

---

## [Июнь 2026] Запуск регистра

Первая публикация. Базовый набор из 20 компонентов с GDPR/CCPA соответствием на момент запуска.

**Источники, на основе которых выстроен текущий чеклист:**
- CNIL Guidelines 2022 — symmetric prominence of accept/reject controls
- CCPA §1798.120 / CPRA §1798.135 — Do Not Sell or Share
- European Accessibility Act, вступил в силу июнь 2025
- WCAG 2.1 — используется как базовый уровень accessibility

**Прецеденты, учтённые при разработке checklist:**
- CNIL, декабрь 2024 — штрафы за asymmetric button contrast
- Honda, март 2025 — $632,500 штраф за asymmetric click count (opt-out требовал больше кликов чем opt-in)

*Следующие записи будут добавляться по мере появления новых регуляторных разъяснений. Если ты заметил изменение в гайдлайнах CNIL, ICO, или другого регулятора, которое касается компонентов в реестре — открой issue с тегом `regulatory-update`.*
